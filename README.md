# Prodigy-Infotech-Virtual-Intern
This repository showcases my completed tasks as part of the Generative AI Virtual Internship offered by Prodigy InfoTech in April 2025. Over the course of the internship, I explored various cutting-edge AI techniques focused on text and image generation, applying theoretical concepts in real-world implementations.

✅ Tasks Completed
1️⃣ Text Generation with GPT-2
  1. Fine-tuned the GPT-2 language model using the Hugging Face transformers library.
  2. Trained on a custom dataset to generate coherent and contextually relevant text.
  3. Gained experience with model training, tokenization, and inference using pipelines.

2️⃣ Image Generation from Text Prompts
  1. Used pre-trained models like Stable Diffusion and DALL·E Mini to generate images from natural language prompts.
  2. Experimented with Hugging Face Diffusers and third-party notebooks to explore creative AI use cases.

3️⃣ Text Generation with Markov Chains
  1. Built a lightweight, probabilistic text generation engine using the markovify library.
  2. Demonstrated the difference between statistical and neural approaches to language modeling.

4️⃣ Image-to-Image Translation with CGAN (Pix2Pix)
  1. Implemented Pix2Pix using TensorFlow’s Conditional GAN architecture.
  2. Translated map outlines into building facades using paired datasets.
  3. Understood adversarial training dynamics and U-Net based generators.

5️⃣ Neural Style Transfer
  1. Applied artistic styles (e.g., famous paintings) to content images using TensorFlow Hub.
  2. Combined convolutional feature representations of content and style in a visually compelling output.
